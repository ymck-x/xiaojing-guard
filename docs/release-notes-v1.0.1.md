# 小鲸守护 v1.0.1

给孩子的平板按家长定的规矩限时。**不联网、不上传任何数据。**

## 这一版换掉了吉祥物

旧版用的是社区二创立绘，授权链不完整，不能用于商业分发。这一版换成了**全新原创角色**——薄荷绿短发、白色卫衣、贝壳发夹的 Q 版鲸鱼娘，和原来的蓝发女仆形象没有任何关系。

如果你装过 v1.0.0，请直接覆盖安装升级。

## 下载

`xiaojing-guard-v1.0.1.apk`（约 7 MB，Android 8.0+）

安装需要允许「安装未知来源应用」。部分机型（ColorOS / OriginOS）会提示「受限制的设置」，需要去应用信息页解除，否则无障碍开不起来。

首次启动会请求「读取已安装应用列表」，用于让家长逐个分类应用，点允许即可。

## 功能

- 每日总时长 / 单次连续时长 + 强制休息 / 停机时段（跨零点）
- 分应用规则：学习不计时、娱乐计额度、禁止直接弹回桌面
- 单应用限额（比如抖音每天 20 分钟）
- 到点整屏锁死，孩子关不掉；家长凭密码解锁或临时放行
- 禁止进入设置、手机管家、应用商店、文件管理（防止孩子自己关掉守护）
- 卸载保护（设备管理器）
- 无障碍授权被系统清掉时主动发通知——覆盖安装、系统升级后会发生

## 已知限制

- 依赖无障碍权限。系统安全模式可绕过（需要厂商级权限才能防），恢复出厂同样会清除。
- 覆盖安装或系统升级后，系统会清空无障碍授权，应用会推送「小鲸守护已失效」提醒，点一下重新开启即可。
