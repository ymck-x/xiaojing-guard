服务器：`dl.speakve.com`（182.254.157.23，Ubuntu 22.04，nginx）
下载目录：`/var/www/xiaojing-dl/`

## 默认方案：固定地址 + 访问密码（全自动，零手动）

**下载地址**
```
https://dl.speakve.com/xj/pro/xiaojing-guard-pro.apk
```
**账号 `kf` / 密码 `brp4q84x`**

买家付款后，在「赞助者可见」的动态里就能看到这组账号密码，自己下载。**你一次都不用动。**

无密码或密码错误一律返回 401（已验证）。

### 换密码（链接泄露时）

```powershell
# 1. 在服务器上重设密码
ssh -i C:\Users\Administrator\.ssh\speakveZG.pem ubuntu@182.254.157.23 "sudo htpasswd -cb /etc/nginx/xj.htpasswd kf '新密码' && sudo systemctl reload nginx"

# 2. 把爱发电那条动态里的密码改成新的
```
老买家仍然能看到最新动态，泄露的人拿着旧密码进不来。

### 发新版怎么办

只需要覆盖服务器上那一个文件：

```powershell
cd E:\fangchenmi
scp -i C:\Users\Administrator\.ssh\speakveZG.pem "dist\xiaojing-guard-1.2.0-pro.apk" ubuntu@182.254.157.23:/tmp/xj-pro.apk
ssh -i C:\Users\Administrator\.ssh\speakveZG.pem ubuntu@182.254.157.23 "sudo mv /tmp/xj-pro.apk /var/www/xiaojing-dl/pro/xiaojing-guard-pro.apk && sudo chown www-data:www-data /var/www/xiaojing-dl/pro/xiaojing-guard-pro.apk"
```

地址不变、密码不变，**所有老买家下次点同一个链接就拿到新版**。

## 可选方案：一单一链（需要手动，链接不可传播）

```powershell
.\tools\publish-apk.ps1 -Apk "dist\xiaojing-guard-1.2.0-pro.apk" -Days 7
```

打印一条 `https://dl.speakve.com/xj/<32位token>/xiaojing-guard-pro.apk`，7 天后服务器自动删除。

适用于：想让每次下载都能追溯到具体订单、或者给特殊客户单独发。

## 可选方案：带买家水印的包

```powershell
.\tools\make-pro-apk.ps1 -Name "张三"
```

生成的包里「关于」页会显示「授权给 张三」。**注意**：每个包都不一样，发新版时要给所有老买家重新打包，量大了不划算——默认不用。

## 服务器上的东西

| 路径 | 作用 |
|---|---|
| `/var/www/xiaojing-dl/pro/` | 固定地址的下载文件（带 basic auth） |
| `/var/www/xiaojing-dl/<token>/` | 一单一链的临时文件 |
| `/etc/nginx/xj.htpasswd` | 下载密码 |
| `/usr/local/bin/xj-cleanup.sh` | 每天 04:00 清理过期的一单一链目录 |
| `/etc/nginx/sites-available/dl-speakve` | 新增了 `/xj/pro/` 和 `/xj/` 两个 location；改动前备份为 `.bak-20261031-221418` |

原有 speakve 站点（`dl.speakve.com` 根目录的 `spd.bin` 等）**未做任何改动**。
