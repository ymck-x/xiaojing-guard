# 小鲸守护 v1.2.0

给孩子的平板按家长定的规矩限时。**不联网、不上传任何数据。**

## 这一版加了购买入口

免费版家长设置里新增「升级到付费版」，点「打开购买页」直接跳到购买页；付款后私信作者领取专属下载链接。

其余同 v1.1.0：免费版管总时长、停机时段、整屏锁；付费版多出分应用限额、护眼强制休息、更多临时解锁次数。

## 免费版与付费版

| 功能 | 免费版 | 付费版（19.9 元） |
| --- | --- | --- |
| 每日总时长 + 到点整屏锁 | ✅ | ✅ |
| 停机时段（睡觉时间） | ✅ | ✅ |
| 家长密码 / 防卸载 / 失效提醒 | ✅ | ✅ |
| 学习类不计时 | ✅ | ✅ |
| 禁止名单 | 最多 3 个应用 | 不限 |
| 单应用限额（抖音每天 20 分钟） | ❌ | ✅ |
| 单次连续 + 强制休息（护眼） | ❌ | ✅ |
| 临时解锁 | 每天 1 次 × 10 分钟 | 每天 3 次，时长可调 |

付费版与免费版**同包名、同签名**，直接覆盖安装即可升级，已设好的规则和累计时长全部保留。

## 下载

`xiaojing-guard-1.2.0-free.apk`（6.8 MB，Android 8.0+）

安装步骤：

1. 点开 APK，允许「安装未知来源应用」。
2. 部分机型（ColorOS / OriginOS）会提示「受限制的设置」，需要去应用信息页解除，否则无障碍开不起来。
3. 首次启动会请求「读取已安装应用列表」，用于让家长逐个分类应用，点允许即可。
4. 按引导三步完成：设密码 → 开无障碍 → 开守护。

## 已知限制

- 依赖无障碍权限。系统安全模式可绕过（需要厂商级权限才能防），恢复出厂同样会清除。
- 覆盖安装或系统升级后，系统会清空无障碍授权，应用会推送「小鲸守护已失效」提醒，点一下重新开启即可。
