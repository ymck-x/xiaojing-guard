### 交付细节

- 文件名：`小鲸守护-v1.0.0.apk`
- 附一页安装图文（很多人不会装 APK，这段决定转化率）：
  1. 点开 APK → 允许「安装未知来源应用」
  2. 部分机型（ColorOS / OriginOS）会提示「受限制的设置」，去应用信息页解除
  3. 打开后按引导三步：设密码 → 开无障碍 → 开守护
- **覆盖升级后无障碍会被系统清空**，应用会推「小鲸守护已失效」通知，点它重开即可——这句话要写进售后话术。

## 3. 宣传

### 只打三个点

1. **不联网**——家长控制类应用里最稀缺的承诺。
2. **不是一刀切**——学习不限时、抖音 20 分钟、游戏禁止，按应用分别设。
3. **小孩不抵触**——小鲸 + 「时间被我吃光啦」，不是冷冰冰的「已锁定」。

### 渠道优先级

1. 小红书 / 抖音自然流量（30 秒对比视频，脚本见下）
2. 家长社群、私域微信群
3. 二手平台 / 闲置群（意外地有效）

**不要投流**：19.9 的客单价，投流一个下载 10~30 元，必亏。

### 视频脚本（30 秒竖屏）

| 秒 | 画面 | 字幕/旁白 |
| --- | --- | --- |
| 0–3 | 孩子抱平板，家长喊吃饭没反应 | 「说了一百遍都不听」 |
| 3–8 | 家长拿走平板，展示安装界面 | 「后来我给它装了个东西」 |
| 8–18 | 录屏：到点弹出小鲸锁屏；家长输密码解锁 | 「到点自己锁，不吵不闹」 |
| 18–26 | 录屏：分应用限额设置、护眼休息 | 「学习不限时，抖音 20 分钟，玩 30 分钟强制休息」 |
| 26–30 | Logo + 名称 | 「小鲸守护，不联网，19.9」 |

工具：系统录屏 + 剪映（免费，自动字幕，BGM 选「可商用」标签）。

**三条红线**：不拍孩子正脸；不说「防沉迷」「戒网瘾」（监管词 + 医疗宣称）；视频里不放下载链接（判站外导流）。
